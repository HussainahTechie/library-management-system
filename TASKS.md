# Team Tasks and 7-Day Plan

Create one GitHub Issue per task below, assign it, and track on a Project board.

## Member 1 - Team Lead
- [ ] Create the public repo, add all 4 members as collaborators
- [ ] Push this starter code, enable branch protection on `main`
- [ ] Create issues, labels (bug, enhancement, good first issue) and project board
- [ ] Review and merge every pull request
- [ ] Finish `main.py` (better input validation, clearer menu)
- [ ] Prepare the demo

## Member 3 - Members (`library/members.py`)

## Member 4 - Loans (`library/loans.py`)
- [ ] available_copies  - [ ] issue_book  - [ ] return_book
- [ ] overdue_loans  - [ ] member_loans

## Member 5 - Docs and Tests
- [ ] Fill in names in README, add screenshots
- [ ] Write tests in tests/test_books.py, test_members.py, test_loans.py
- [ ] Create 3 "good first issue" issues for outside contributors
- [ ] Collect evidence: screenshots of commits, PRs, issues, contributors graph

## Timeline
| Day | Goal |
|---|---|
| 1 | Repo live, license, README, issues created, everyone clones |
